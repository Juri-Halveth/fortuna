# FORTUNA

**Краткий путеводитель по проекту · EN / RU**

FORTUNA сравнивает введённые пользователем варианты по вероятности, доходу, затратам, радости, устойчивости и риску. Описанное локальное приложение Windows также помогает упорядочивать окна и восстанавливать их прежнее положение. Публичный репозиторий содержит браузерную поведенческую симуляцию; исходная README отличает её от локального настольного приложения.

Браузерный коллектив показывает веса и отдельные результаты 69 профилей персонажей и Fortuna. Это расчёты на основе введённых данных. Измеренное улучшение удачи, результатов внешних игр или вероятности выигрыша в казино не показано; FORTUNA не обещает выигрыша.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
