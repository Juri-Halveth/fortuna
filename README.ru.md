# Fortuna · Эксперимент с вероятностью и сравнение вариантов

**Локальный эксперимент с вероятностью и отдельное сравнение вариантов.**
Браузер использует Web Crypto для **999 999 попыток на серию**, сравнивает
исходную вероятность с заданным сценарием и считает попадания. Также можно
ввести варианты, посмотреть веса и оценки. Персонажи работают по локальным
правилам.

[Открыть приложение](https://juri-halveth.github.io/fortuna/) · [Портфолио](https://juri-halveth.github.io/ru/)

В опубликованных исходниках: `docs/rng-lab.mjs` и `docs/rng-panel.mjs` для
ограниченного локального эксперимента с отменой, `docs/collective.mjs` для сравнения вариантов,
`docs/curiosity.mjs` для поведения персонажей, интерфейс и тесты моделей.

```sh
node --test docs/*.test.mjs
python -c "import http.server, os; os.chdir('docs'); http.server.SimpleHTTPRequestHandler.extensions_map['.mjs']='text/javascript'; http.server.test(HandlerClass=http.server.SimpleHTTPRequestHandler,port=8849,bind='127.0.0.1')"
```

Откройте `http://127.0.0.1:8849/`. Здесь опубликована браузерная версия.
Ранее описанный локальный инструмент Windows не имеет здесь нативных исходников
или EXE-файла. Попытки относятся только к собственной модели Бернулли и не
меняют вероятность исхода на чужом сервере. Оценки следуют введённым данным.
Все профили используют одну локальную систему правил.
